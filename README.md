# Employee Leave Management System

## Tech Stack
- Java 17
- Spring Boot
- Spring Security (JWT)
- MySQL
- Swagger
- Docker

## Features
- JWT Authentication
- Role Based Access Control
- Leave Apply & Approval Workflow
- Exception Handling
- API Documentation

## Architecture
Layered Monolithic Architecture:
Controller → Service → Repository

## Run Locally
1. Configure DB in application.yml
2. mvn clean install
3. Run LeaveManagementApplication

## Swagger
http://localhost:8080/swagger-ui.html
